# 전자책 링크 공통 적용 기록

작업일: 2026-10-24 · 사용자 지정 링크: **https://litt.ly/roky.studio**

## 동작과 신규 개발 기준

스튜디오와 모든 프로젝트의 공통 메뉴에 **전자책** 버튼을 추가한다. 새 탭으로 열며 사용 중인 게임·도구는 유지한다. 웹 버튼은 높이 44px 이상과 키보드 초점 표시를 제공한다. 기존 소셜·후원 버튼과 현재 프로젝트의 기술은 유지한다.

`PROJECT_BASELINE.md`의 기본 원칙·체크리스트·복사용 개발 요청·11절에 기록했다. 모든 프로젝트의 기존 AGENTS.md는 이 기본 문서를 참조한다. Google Play판의 외부 전자책 구매 동선은 현행 결제 정책을 확인하고 배포 채널별로 결정한다. 이번 작업은 웹 링크 추가다.

추가 사용자 요청도 반영했다. 12절은 한국어·영어·일본어·중국어 지원, 언어 선택 저장, 공통 문구·오류·업데이트 번역과 검증 기준을 정한다. 9절과 13절은 후원 진입점 하나에서 Buy Me a Coffee와 카카오뱅크 계좌번호 복사를 선택하는 흐름, 복사 실패·수동 선택·접근성·배포 채널 기준을 정한다. 기존 앱 전체 번역이 이번 문서 추가만으로 완료된 것으로 기록하지 않는다.

용사월드와 워킷은 기존 배포 채널 환경 변수, 탁구왕은 기존 `ClubConfig.distributionChannel` 설정이 `google-play`이면 새 전자책 버튼을 노출하지 않는다. 다른 프로젝트는 웹 메뉴의 `data-web-only-commerce`를 Android 패키징 검토 대상으로 표시한다.

## 확인 범위

- 로컬 브라우저의 390px 화면에서 11개 프로젝트의 전자책 링크 높이 44px·화면 안 배치·새 탭 속성을 확인했다. 스튜디오는 1280px에서도 확인했다.
- 스튜디오의 링크 클릭은 지정 주소의 새 탭을 열며 원래 화면을 유지했다. 주소 자체의 HTTP 200 응답도 확인했다.
- 키보드 초점은 스튜디오·워킷·용사월드 등에서 확인했다. 탁구왕은 초기화 중 게임이 초점을 가져가는 동작이 있어 모든 플레이 상황의 키보드 접근성까지 검증 완료로 표시하지 않는다.
- 이미지 일부와 게임/외부 통신을 제한한 메뉴 확인이다. 이번 링크 변경으로 전체 게임·로그인·실제 Android 기기의 기능을 전수 검증했다는 의미는 아니다.
- 동시에 변경된 후원 선택 창·계좌 복사와 프로젝트별 최신 코드를 보존해 합쳤다. 워킷의 배포 HTML 23개에는 최신 후원 동작도 유지했다.
