# 후원 페이지 전환 — 2026-10-24

사용자가 개설하고 제공한 실제 주소: https://buymeacoffee.com/roky.studio

- 공개 페이지 HTTP 200, 표시 이름 `roky.studio`, 공공 앱과 게임 개발 소개와 후원 화면을 읽기 전용으로 확인했다.
- 공통 유도 문구는 `더 좋은 앱을 위한 후원` / `후원하기`, 짧은 설명은 `더 좋은 앱을 만들 수 있도록 후원해주세요.`로 통일했다.
- 후원 페이지는 새 탭으로 연다. 추가 사용자 요청에 따라 국내 이용자를 위해 카카오뱅크 계좌 복사 버튼을 옆에 함께 제공한다. 이름은 표시하지 않는다. 외부 결제 위젯이나 추적 스크립트를 추가하지 않았다.
- 이전 프로젝트에서 사용하는 `#bank-transfer` 주소는 계속 지원하며, 방문자는 새 후원 안내와 Buy Me a Coffee 버튼을 볼 수 있다.
- 오늘의 퍼즐 웹 원본과 배포 HTML의 버튼도 `로키스튜디오 후원`으로 바꾸고 새 페이지로 직접 연결한다.
- 스튜디오·오늘의 퍼즐·용사월드·탁구왕·스트레스 브레이크·워크잇의 모든 도구 페이지·산책길·작은정원·전자책 예제·에이전트뷰·코트러시에 같은 후원 문구와 실제 링크를 적용했다. 코트러시는 기존 로컬 시제품 상태를 유지한다.
- 11개 프로젝트를 로컬 Chromium 390px 화면에서 확인했다. 링크 문구·정확한 목적지·새 탭 열기·모바일 버튼 배치를 검사했다. 게임 플레이 전체를 다시 검사했다는 뜻은 아니다.
