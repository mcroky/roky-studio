# 카카오뱅크 공통 버튼과 Google Play 개발 기준

작업일: 2026-10-24

## 공통 동작

- 웹 버튼: **카카오뱅크 이체** → [Roky Studio 계좌 안내](https://mcroky.github.io/roky-studio/#bank-transfer).
- 은행 **카카오뱅크**, 계좌 **3333071025774**. 사용자가 제공한 계좌 정보를 홈페이지 한 곳에서 관리하고 예금주 이름은 직접 표시하지 않는다.
- 같은 날 사용자 요청으로 후원 목적(공공·생활 앱 개발·운영, 새 기능·오류 수정·사용성 개선)과 자율 선택 안내를 추가했다. 계좌 정보는 `계좌로 후원하기`를 선택하면 펼쳐진다.
- 계좌 복사 후 은행 앱에서 직접 이체한다. 자동 송금·입금 확인·게임 보상 지급 기능은 없다.
- 각 앱은 새 탭으로 안내를 열어 사용 중인 게임·도구를 유지한다. 복사가 차단되면 계좌번호를 선택하고 직접 복사할 수 있다고 안내한다.
- 웹 버튼은 44px 이상 터치 영역과 초점 표시를 제공한다. 중앙 복사 버튼은 48px 이상이다.

## Google Play를 전제로 한 다음 개발

[공통 개발 기준](../PROJECT_BASELINE.md)과 [Google Play 출시 준비 기준](GOOGLE_PLAY_READINESS.md)에 사용자 요청을 기록했다. 모든 프로젝트의 `AGENTS.md`에 세 공통 문서의 실제 경로를 연결했다.

처음부터 Android 빌드 경로·터치·뒤로가기·앱 전환·저장 이관·개인정보·권한·계정 삭제·서명·AAB·정책·기기 검증을 계획한다. 이번 작업에서 Android 앱이나 Google Play 출시는 수행하지 않았다.

웹의 이체 버튼을 Play 앱에 자동 포함하지 않는다. 용사월드는 `VITE_DISTRIBUTION_CHANNEL=google-play`, 워킷은 `NEXT_PUBLIC_DISTRIBUTION_CHANNEL=google-play`, 탁구왕은 `window.ClubConfig.distributionChannel='google-play'`일 때 새 이체 링크를 만들지 않는다. 다른 웹 전용 프로젝트의 `data-web-only-transfer` 링크도 Android 패키징 시 정책 확인 결과에 따라 포함 여부를 결정해야 한다. 이 표식만으로 링크가 자동 제거되는 것은 아니다. 기존 홈페이지 링크를 통한 간접 결제 경로도 출시 시 점검한다.

현재 정책의 예외·API 기준·테스트 요건과 공식 출처는 출시 준비 문서에 확인일과 함께 기록했다. 제출 전에 다시 확인한다.

## 검증의 한계

기본 브라우저 연결 도구는 Windows 실행 환경 오류로 시작하지 못했다. 별도 로컬 Edge 자동화로 아래를 확인했다. 실제 Android 휴대폰·송금·Play 결제 검증은 수행하지 않았다.

- 홈페이지 계좌 복사 성공, 클립보드 API가 없을 때 계좌 선택·직접 복사 안내·버튼 재활성화.
- 홈페이지 390px·1280px 너비에서 가로 넘침 없음, 복사 버튼 높이 50px.
- 작은정원 390×844 화면에서 Godot 게임 시작 완료, 게임 영역 390×788과 이체 메뉴 분리, 조작을 덮지 않는 배치.
- 오늘의 퍼즐 390px 화면에서 실제 Godot 웹 실행, 이체 버튼 높이 44px, 가로 넘침 없음.
- 다른 프로젝트는 해당 빌드·문법·링크와 배포 파일을 확인한다. 모든 게임의 플레이 흐름을 다시 전수 검증했다는 뜻은 아니다.
