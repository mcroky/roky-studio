# 쉬기 좋은 곳 찾기 · 첫 배포 실습

중3 스튜디오 실습을 위한 정적 웹페이지입니다. 장소 A, B, C와 모든 조건은 **가상 자료**입니다.

## 실행

`index.html`을 브라우저에서 엽니다. 별도 설치나 API 키는 필요하지 않습니다.

## 확인할 것

1. 조건을 고르지 않으면 안내 문구가 보입니다.
2. `그늘`만 고르면 A와 C가 1점, B가 0점입니다.
3. `그늘`과 `앉을 곳`을 고르면 A가 2점, B와 C가 1점입니다.
4. 세 조건을 모두 고르면 A, B, C가 모두 2점입니다.
5. 휴대전화 너비에서도 조건과 결과를 읽을 수 있습니다.

## 배포

GitHub에 별도 공개 저장소를 만들고 이 폴더의 네 파일을 저장소 루트에 올립니다. 저장소의 **Settings → Pages**에서 **Deploy from a branch**, `main`, `/(root)`를 선택한 뒤 제공되는 사이트 주소에서 다시 시험합니다.

개인정보, 실제 통학 경로, 비밀키를 공개 저장소나 사이트에 올리지 않습니다.
